Run the selected policy to calculate interception performance over shared, reproducible scenarios.

Partial observability

The policy receives a noisy alert only from the selected band. Occupancy on every other band remains hidden, which turns scan scheduling into a time-and-frequency search problem.

Emitter mix

Each run combines a fixed periodic scanner, a frequency-agile hopper, and a Markov burst transmitter. Sensor misses, false alarms, and retunes are modeled explicitly.

Interpret results carefully

These are comparisons inside a synthetic model, not predictions of real-world RF interception. The full source code and assumptions are included in the repository.
